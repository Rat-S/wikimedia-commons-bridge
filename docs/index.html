Wikimedia Commons Bridge

A secure, privacy-first web application designed to help photographers and community contributors publish curated media directly from Google Photos to Wikimedia Commons under open licenses.

Launch App on Toolforge → View Privacy Policy
🔒

Scoped Picker Access

Uses the official Google Photos Picker API. We only access media items that you explicitly select during your active session. We never request full library read access.

🚀

Zero Storage Transfer

Images are streamed concurrently in memory from Google Photos directly to Wikimedia Commons APIs. No photos are stored on persistent server disks.

🏷️

Wikimedia Metadata

Easily edit captions, multilingual descriptions, structured categories, and licensing metadata before committing uploads to Wikimedia Commons.

Data Protection & Open Licensing Compliance

The Wikimedia Commons Bridge operates in full compliance with the Google API Services User Data Policy, including Google's Limited Use requirements.

All contributions are voluntarily published by authorized copyright holders to Wikimedia Commons under Creative Commons open licenses (e.g., CC BY-SA 4.0 or CC0 1.0).
